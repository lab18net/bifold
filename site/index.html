Two panes. One keyboard.

A dual-pane file manager in the classic commander tradition. The left pane is where you are, the right pane is where you are going. Run it in the terminal or as a native window: both are the same program on one shared core.

brew install lab18net/tap/bifold

Install

Everything below is published from the same repository. Homebrew formulae and the cask live in the lab18net/tap tap.

Terminalformula bifold

brew install lab18net/tap/bifold

Builds from the tagged source with Homebrew's Rust and installs the bifold command and its man page. Takes about a minute.

macOS appcask bifold-app

brew install --cask lab18net/tap/bifold-app

The prebuilt Bifold.app for Apple silicon, installed to /Applications. It is signed ad hoc and not notarised yet, so the cask clears the quarantine flag for you.

Desktop, from sourceformula bifold-gui

brew install lab18net/tap/bifold-gui

The same window as a bifold-gui command, compiled on your machine.

With CargoRust 1.88+

cargo install --git https://github.com/lab18net/bifold --locked bifold-tui

Add bifold-gui for the desktop window. Release builds are also attached to each GitHub release with checksums.

Built to stay out of your way

The behaviour that matters is in the core, so the terminal UI and the desktop window act the same.

Copy and move run in the background

Transfers show progress and can be cancelled. Only one runs at a time, and links are recreated, never followed.

Deleting is reversible

Files go to the Trash after a confirmation. Permanent deletion has to be switched on in the config.

A viewer for everything

Text, a hex dump for binary files, and an optional lf-style external previewer, time-boxed and output-capped.

Run programs in place

Enter on an executable opens a prefilled command line in the current folder. Ctrl+O shows the terminal.

Your keys, your config

Every binding is data in ~/.config/bifold/config.toml, shared by both front ends. h opens a help screen generated from your live keymap.

The config file stays yours

Bifold edits it in place and writes only what changed. Comments, unknown keys and ordering survive, and a file that does not parse is never overwritten.

Tab completion in every prompt

Paths and commands complete in all text inputs, in both front ends.

Themes

nord, gruvbox, solarized, light variants and the terminal's own colours, plus your own theme files.
